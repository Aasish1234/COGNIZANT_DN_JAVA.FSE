## Repository Architecture

The codebase is organized into weekly milestones mapped directly to the Java FSE curriculum:

* **`Week1`**
  * Practical implementations of Design Patterns and Principles, along with foundational Data Structures and Algorithms.
  * Comprehensive hands-on coverage of PL/SQL Programming, Test-Driven Development (TDD), and Java Logging Frameworks.

* **`Week2`**
  * Core backend dependency management setups utilizing Spring Core frameworks alongside Apache Maven compilation structures.
  * Enterprise database connectivity implementations featuring Spring Data JPA mapped with Spring Boot integrations and Hibernate ORM logic.

* **`Week3`**
  * Enterprise RESTful API architectures engineered through Spring REST tools inside the Spring Boot 3 framework layer.
  * Focuses on automated standard HTTP status codes, entity validation pipelines, and controller endpoints routing patterns.

* **`Week4`**
  * Automated codebase maintenance setups employing automated static analysis routines and SonarQube validation platforms.
  * Multi-service distributed backend networks running on decoupled Microservices configurations engineered through Spring Boot 3 and Spring Cloud ecosystem architectures.

* **`Week5`**
  * Frontend architecture engineering focusing on developing scalable component-driven Single Page Applications (SPAs).
  * Implementation of state management, modular rendering, and reactive user interfaces built via Angular / React frameworks.

* **`Week6`**
  * Advanced modular UI development using client-side architectures alongside streamlined version management via Git workflows.
  * Setup and orchestration of automated deployment strategies leveraging Continuous Integration and Continuous Deployment (CI/CD) pipelines.
